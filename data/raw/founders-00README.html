Founders Online Metadata

Files in this directory:

founders-online-metadata.xml
A simple XML representation of basic metadata for all documents in Founders Online (founders.archives.gov)
founders-online-metadata.json
A simple JSON representation of basic metadata for all documents in Founders Online
founders-online-metadata-format.pdf
Data dictionary for the metadata formats
timestamp.txt
Date and time of last modification of the XML and JSON files (can be used for scripted downloads, to avoid re-downloading an existing file)

Note: Owing to their size, the XML and JSON files will be sent with the header "Content-Disposition: attachment", so that they will be downloaded directly rather than being displayed in the browser.

Metadata files are updated within 24 hours following any content change to the Founders Online document database. For any questions, please contact foundersonline@nara.gov.
